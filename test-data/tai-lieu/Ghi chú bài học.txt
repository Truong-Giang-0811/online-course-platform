GHI CHÚ BÀI HỌC – JAVASCRIPT CƠ BẢN

1. Khai báo biến
   - let: biến có thể gán lại
   - const: hằng, không gán lại được

2. Hàm
   function cong(a, b) { return a + b; }
   const nhan = (a, b) => a * b;

3. Vòng lặp
   for (let i = 0; i < 5; i++) console.log(i);

Bài tập: viết hàm tính tổng các số chẵn từ 1 đến n.
